# Plano de Melhorias - Sistema Financeiro 2025

## 1. Melhorias Visuais (UI/UX)
- **Paleta de Cores**: Atualizar para cores mais modernas e profissionais, utilizando tons de azul marinho, cinza suave e acentos vibrantes para estados (sucesso, erro, alerta).
- **Cards de Resumo**: Redesenhar os cards do dashboard com sombras mais suaves, bordas arredondadas e ícones representativos.
- **Sidebar**: Melhorar a navegação com estados ativos mais claros e transições suaves.
- **Tipografia**: Ajustar pesos e tamanhos de fonte para melhor hierarquia visual.
- **Modo Escuro**: Implementar suporte nativo a tema escuro (Dark Mode).

## 2. Novas Funcionalidades
- **Metas Financeiras**: Adicionar um módulo para criar e acompanhar metas de economia (ex: Reserva de Emergência, Viagem).
- **Gráficos Avançados**: Implementar novos gráficos de evolução mensal e comparação de gastos.
- **Sistema de Alertas**: Notificações visuais para contas próximas do vencimento e orçamentos estourados.
- **Filtros Dinâmicos**: Melhorar a filtragem de transações por período, categoria e conta.

## 3. Ajustes Open Finance (Foco InfinitePay)
- **Remoção de Outros Bancos**: Limpar o código de integração para manter exclusivamente a conexão com o InfinitePay.
- **Interface Simplificada**: Ajustar a tela de conexão para que o usuário conecte diretamente ao InfinitePay sem necessidade de seleção de múltiplos bancos.
- **Sincronização Automática**: Melhorar o feedback visual durante a sincronização de dados do InfinitePay.

## 4. Refatoração Técnica
- **Limpeza de Código**: Remover arquivos obsoletos (ex: `index10-06`, `Index novo`).
- **Otimização de Performance**: Melhorar o carregamento de dados e renderização de gráficos.
